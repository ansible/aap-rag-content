# Build execution environments with automation portal

Use execution environment builder in Ansible automation portal to create, configure, and build custom execution environments for your automation workloads.

To set up and use execution environment builder, complete the following steps:

1. Configure collection discovery sources for your Git repositories and private automation hub.
2. Connect to your Git provider — configure authentication for content discovery, saving definitions, and automated builds for GitHub or GitLab.
3. Configure wizard templates — host templates in a private repository if needed, and enable cloud or network automation templates.
4. Create standardized templates for your teams.
5. Synchronize content sources.
6. Configure permissions — grant execution environment builder access to non-admin users.
