# Set up execution environment builder

Configure permissions, connect your Git provider, and set up content sources before users can create and build execution environments.

Complete the following steps to set up execution environment builder:

1. Configure collection discovery sources for your Git repositories and private automation hub.
2. Connect to GitHub — configure a GitHub App or PAT for content discovery, and an OAuth App for saving definitions.
3. Connect to GitLab — configure a PAT for content discovery, an OAuth App for saving definitions, and CI/CD variables for automated builds.
4. Configure wizard templates — host templates in a private repository if needed, and enable cloud or network automation templates.
5. Create standardized templates for your teams.
6. Synchronize content sources.
7. Configure permissions — grant execution environment builder access to non-admin users.
