# Migrate from existing deployment topologies

Learn about supported migration paths between container-based, OpenShift Container Platform, and Managed Ansible Automation Platform deployments, including step-by-step workflows and migration requirements.

Important:

RPM-based deployments are not available in Ansible Automation Platform 2.7. For migration paths from RPM-based deployments, see the Ansible Automation Platform migration content for 2.6.

The supported migration paths include:

| Source environment                          | Target environment                  |
| ------------------------------------------- | ----------------------------------- |
| Container-based Ansible Automation Platform | OpenShift Container Platform        |
| Container-based Ansible Automation Platform | Managed Ansible Automation Platform |

Migrations outside of those listed are not supported at this time.
