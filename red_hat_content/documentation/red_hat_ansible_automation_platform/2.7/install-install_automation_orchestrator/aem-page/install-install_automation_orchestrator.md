# Install automation orchestrator

Automation orchestrator is an optional component of Ansible Automation Platform. You can install automation orchestrator on Red Hat OpenShift Container Platform using the operator, the OpenShift CLI, or the aapctl CLI.

To install automation orchestrator, see [Install and manage automation orchestrator](https://docs.redhat.com/en/documentation/automation_orchestrator/2026.8/install-install_and_manage_automation_orchestrator) in the automation orchestrator documentation.
