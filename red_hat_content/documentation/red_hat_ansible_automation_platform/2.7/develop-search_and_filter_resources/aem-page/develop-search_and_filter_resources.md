# Search and filter resources

You can search and filter lists of jobs, projects, inventories, templates, and other resources in Ansible Automation Platform to quickly locate specific items.

The search bar on each list page accepts field-based queries and simple string searches. Select the Name drop-down menu in the search field to view the available search criteria for that page.
