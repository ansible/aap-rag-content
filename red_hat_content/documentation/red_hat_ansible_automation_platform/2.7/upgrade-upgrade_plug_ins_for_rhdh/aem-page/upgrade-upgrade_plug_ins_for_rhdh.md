# Upgrade Ansible plug-ins for Red Hat Developer Hub

The Ansible plug-ins for Red Hat Developer Hub integrate Ansible Automation Platform capabilities into your developer portal. You can upgrade the plug-ins to access new features, bug fixes, and security patches.

Red Hat releases updated versions of the Ansible plug-ins to deliver new features, fix bugs, and address security vulnerabilities. Upgrading ensures that you have the latest supported version of the plug-ins and that they remain compatible with your RedHat Developer Hub and Ansible Automation Platform versions.
