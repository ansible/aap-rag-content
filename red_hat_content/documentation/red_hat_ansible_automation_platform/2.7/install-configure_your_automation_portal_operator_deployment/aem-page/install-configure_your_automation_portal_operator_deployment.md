# Configure your automation portal operator deployment

Customize your automation portal deployment by modifying the `AutomationPortal` custom resource fields for authentication, plugins, networking, and infrastructure.

Important:

The automation portal operator is a Technology Preview feature only. Technology Preview features are not supported with Red Hat production service level agreements (SLAs) and
 might not be functionally complete. Red Hat does not recommend using them in production.
