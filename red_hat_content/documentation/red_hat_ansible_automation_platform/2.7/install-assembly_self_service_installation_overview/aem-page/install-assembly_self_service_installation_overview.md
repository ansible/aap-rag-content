# Pre-installation configuration

You can deploy Ansible automation portal from a Helm chart on OpenShift Container Platform.

Helm is a tool that simplifies deployment of applications on Red Hat OpenShift Container Platform clusters.
Helm uses a packaging format called Helm charts.
A Helm chart is a package of files that define how an application is deployed and managed on OpenShift.
The Helm chart for Ansible automation portal is available in the OpenShift Helm catalog.
