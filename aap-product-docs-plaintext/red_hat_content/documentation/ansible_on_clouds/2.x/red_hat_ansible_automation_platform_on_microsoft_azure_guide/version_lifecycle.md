# 1. Introduction to Red Hat Ansible Automation Platform on Microsoft Azure
## 1.9. Product lifecycle and maintenance
### 1.9.1. Version lifecycle

Red Hat Ansible Automation Platform on Microsoft Azure employs a continuous release approach to versioning, meaning that customers are upgraded to the latest version that Red Hat supports on a cadence that Red Hat defines. Ansible Automation Platform on Microsoft Azure cannot be version locked for customers at this time.

As a managed application, Red Hat provides upgrades to the offering as per the cadence defined below to deliver modern application features, product fixes, and security updates.

| <br>  Ansible Automation Platform on Azure                                 | <br>  Ansible Automation Platform                                                                                                 | <br>  Seeded Content                                                       |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| <br>  Continuously Released outside of Ansible Automation Platform version | <br>  Updated to maintain cadence with the most recently published version of Ansible Automation Platform (x.y.z release streams) | <br>  Continuously Released outside of Ansible Automation Platform version |
