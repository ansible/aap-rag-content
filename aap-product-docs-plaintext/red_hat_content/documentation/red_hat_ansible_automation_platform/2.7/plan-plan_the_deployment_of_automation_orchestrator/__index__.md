# Plan the deployment of automation orchestrator

Automation orchestrator is an optional component of Ansible Automation Platform, which can be installed on on Red Hat OpenShift Container Platform. Review the supported deployment models to determine which model that matches your infrastructure requirements and security constraints.

For more information, see [Choose a deployment model](https://docs.redhat.com/en/documentation/automation_orchestrator/2026.8/plan-choose_a_deployment_model) in the automation orchestrator documentation.
