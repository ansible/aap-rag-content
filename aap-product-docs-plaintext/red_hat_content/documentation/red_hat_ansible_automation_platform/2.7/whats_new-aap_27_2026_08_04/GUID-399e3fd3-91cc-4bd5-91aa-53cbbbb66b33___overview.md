# Ansible Automation Platform 2.7 patch release August 4, 2026 (2.7.4)
## Overview

Red Hat Ansible Automation Platform 2.7 (20260804) delivers substantial performance improvements for large-scale deployments — particularly in Gateway's `migrate_service_data` pipeline and Controller's RBAC query paths — new MCP Server capabilities with OAuth Protected Resource Metadata (RFC 9728) support, indirect node metrics collection, over 30 CVE remediations across all platform components, and numerous bug fixes spanning authentication, UI responsiveness, operator backup reliability, and proxy configuration handling.
