# Automate Microsoft Windows with Ansible Automation Platform

Securely manage Microsoft Windows environments at scale. Integrate your hosts into the Red Hat Ansible Automation Platform using recommended architectures to reliably configure, update, and maintain enterprise systems.

Access the recommended practices to successfully automate your Windows tasks using the Red Hat Ansible Automation Platform. Rather than relying on disparate scripts and manual configurations, you will gain the strategies to integrate Windows into your broader enterprise automation strategy.

You can accomplish the following jobs:

- Configure and bootstrap Windows hosts so that they are ready for secure, scalable automation.
- Choose, configure, and troubleshoot connection methods such as WinRM, PSRP, or OpenSSH so that your Ansible control nodes communicate reliably with Windows targets.
- Use dedicated Windows modules, best practices, and foundational PowerShell scripting techniques so that your playbooks are tailored for Windows environments.
- Navigate development setups, non-technical considerations, and supported Red Hat solutions so that you can continually improve the scope and reliability of your Windows automation.

**Support your automation solutions with enterprise tools**

When automating critical Windows infrastructure, ensure your underlying tools are production-ready and fully supported. Ansible Automation Platform provides a supported ecosystem for executing Windows tasks.

As you plan your Windows automation strategy, consider the following to ensure you have the right tools for the job:

- **Rely on production-ready tools:** The Windows automation capabilities within ansible-core are fully tested and ready for production use.
- **Access certified content**: Execute a wide range of tasks using supported modules supplied with your Ansible Automation Platform subscription. You can find collections such as `ansible.windows`, `chocolatey.chocolatey`, `microsoft.mecm`, `microsoft.iis`, and `microsoft.ad `on the Red Hat automation hub.
- **Use community extensions:** For edge cases or tasks outside the core supported modules (such as configuring specific firewall rules), use the `community.windows` collection.
