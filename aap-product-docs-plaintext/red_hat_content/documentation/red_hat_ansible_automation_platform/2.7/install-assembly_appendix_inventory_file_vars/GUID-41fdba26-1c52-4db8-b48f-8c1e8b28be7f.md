# Inventory file variables
## Automation metrics variables

Inventory file variables for automation metrics used with Ansible Automation Platform.

| Variable name                                   | Description                                                                                                                                                                                              | Required or optional                                              | Default                                    |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------ |
| `automationmetrics_controller_read_pg_host`     | PostgreSQL host for read-only access to the automation controller database. Metrics service queries this database to collect use and performance data. Use the same host as `controller_pg_host` for growth topology, or the external database host for enterprise topology. | Required (if installing metrics service)                          |                                            |
| `automationmetrics_controller_read_pg_database` | Name of the automation controller database. Metrics service requires read-only SELECT access to this database.                                                                                           | Optional (if installing metrics service; uses default if not set) | `awx` (or custom controller database name) |
| `automationmetrics_controller_read_pg_username` | PostgreSQL read-only user for the automation controller database. This user is automatically created during installation with SELECT-only privileges on all tables in the public schema.                 | Optional (if installing metrics service; uses default if not set) | `ms_awx_readonly`                          |
| `automationmetrics_controller_read_pg_password` | Password for `automationmetrics_controller_read_pg_username`. Keep this secure and consistent with the read-only database user created.                                                                  | Required (if installing metrics service)                          |                                            |
| `automationmetrics_pg_password`                 | Password for `automationmetrics_pg_username`. Keep this secure and consistent with the database user created during installation.                                                                        | Required (if installing metrics service)                          |                                            |
| `automationmetrics_pg_database`                 | Name of the PostgreSQL database for metrics service data storage.                                                                                                                                        | Optional (if installing metrics service; uses default if not set) |                                            |
| `automationmetrics_pg_username`                 | PostgreSQL user for the metrics\_service database. This user requires ALL privileges on the metrics\_service database.                                                                                   | Optional (if installing metrics service; uses default if not set) |                                            |
| `automationmetrics_pg_host`                     | PostgreSQL host for the metrics\_service database. Use the same host as `controller_pg_host ` for growth topology, or a dedicated external database host for enterprise topology.                        | Required (if installing metrics service)                          |                                            |
| `automationmetrics_skip_install`                | Set to true to skip installation of the metrics service when automation controller is present. When true, omit the `[automationmetrics] `inventory group. When false (default), the `[automationmetrics]` inventory group is required.   Note:   Operator-based (OpenShift) deployments use `spec.metrics.disabled` in the Custom Resource instead. |                                                                   |                                            |
