# Install with Ansible on Clouds

Red Hat Ansible Automation Platform on Clouds is a deployment option for Red Hat Ansible Automation Platform on public cloud marketplaces. You can use Ansible on Clouds to deploy and scale automation across cloud environments without managing underlying infrastructure.

To install with Ansible on Clouds, see the [Ansible on Clouds](https://docs.redhat.com/en/documentation/ansible_on_clouds/2.x) documentation.
