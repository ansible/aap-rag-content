# Disable the MCP server
## Procedure

-  To disable the server from the command palette, find and select **Disable Ansible Development Tools MCP Server**.
-  To disable the server from the settings menu, click the **Settings** wheel ![settings wheel](/webassets/aem/red_hat_ansible_automation_platform/2.7/images/settings-icon-ansible-vscode-extension.png)in the Ansible VS Code extension, navigate to Extensions> (and then)Ansible> (and then)MCP Server and un-check the checkbox next to **Enable the Ansible MCP server for AI integration**.
