# Start a trial of Red Hat Ansible Lightspeed
## Before you begin

- You must have a trial or paid subscription to the Red Hat Ansible Automation Platform.
- You must have installed and configured the Ansible VS Code extension. For the steps, see [Install and configure the Ansible VS Code extension](/documentation/en-us/red_hat_ansible_automation_platform/2.7/develop-assembly_install_ansible_vscode_extension#unique_1725722105 "Red Hat Ansible Lightspeed with IBM watsonx Code Assistant integrates with the Ansible Visual Studio (VS) Code extension. When enabled, the extension automatically collects recommendations, usage telemetry, and Ansible YAML file state through automated events.").
