# Start a trial of Red Hat Ansible Lightspeed
## Before you begin

- You must have a trial or paid subscription to the Red Hat Ansible Automation Platform.
- You must have installed and configured the Ansible VS Code extension. For the steps, see [Install and configure the Ansible VS Code extension](/documentation/en-us/red_hat_ansible_automation_platform/2.7/develop-assembly_install_ansible_vscode_extension#unique_0 "Install and configure the Ansible VS Code extension to use the cloud-hosted coding assistant or a third-party LLM provider (IBM watsonx, Google Gemini). When enabled, the extension automatically collects recommendations, usage telemetry, and Ansible YAML file state through automated events.").
